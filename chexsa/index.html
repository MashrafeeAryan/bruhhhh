The problem

Typing every browser task is not always the most convenient way to interact with a personal assistant.

What I did

Added an optional voice mode that listens for “Hey Chexsa” and transcribes the request before passing it to the agent.

Outcome & status

The repository documents voice-mode startup and optional dependencies. Voice mode must be running; the documented transcription path uses Google Speech Recognition.
