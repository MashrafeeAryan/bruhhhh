NumPy-style einsum in MatX

Make tensor expressions easier to write without spelling out every batch dimension.

  • C++
  • CUDA
  • Tensor APIs
Read the case study +

The problem

MatX einsum required explicit output notation and did not support ellipsis notation for batch dimensions.

What I did

Added implicit output inference and ellipsis syntax, with regression tests for both behaviors. Batch dimensions still need matching sizes because of the underlying cuTensorNet constraint.

Outcome & status

Merged in MatX PR #1224. Expressions such as ...ij,...jk->...ik can now represent matching batch dimensions.

Safer multi-GPU workspace reuse

Address allocation hangs and stale-buffer risks in matmul_all_reduce.

  • Triton
  • Multi-GPU
  • Synchronization
Read the case study +

The problem

If one GPU entered allocation while another skipped it, workers could disagree on a collective operation and hang. Repeated calls also need safe buffer reuse.

What I did

Separated allocation from per-call preparation, made allocation decisions collective, and introduced generation-based synchronization with repeated-call GPU tests.

Outcome & status

Draft PR #581. AMD GPU execution and performance measurements had not been run in the submitted PR, so the fix is presented as work under review.

CUDA Neural Network Engine

Understand neural networks from matrix storage to GPU kernel execution.

  • C++
  • CUDA
  • GoogleTest
Read the case study +

The problem

High-level ML APIs hide the relationship between matrix operations, backpropagation, and compute cost.

What I did

Built matrix operations, dense layers, forward/backpropagation, and a CUDA matrix-multiplication path with correctness tests and CPU/GPU benchmarks.

Outcome & status

The project reports about 704× speedup for 512×512 multiplication on a Colab Tesla T4 versus its own single-threaded CPU implementation, averaged over five trials. This is a project-specific comparison, not a general library benchmark; CUDA is not yet integrated into the training loop.
