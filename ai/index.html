Pulse2BP

Build a reproducible pipeline for cuffless blood-pressure estimation from physiological signals.

  • Python
  • Signal processing
  • scikit-learn
Read the case study +

The problem

Long PPG recordings need to be cleaned, segmented, and aligned with arterial blood-pressure targets before they become usable model examples.

What I did

Working with the team on pipeline integration, dataset structure, train/test design, and reproducible evaluation. The workflow covers preprocessing, feature engineering, and modeling.

Outcome & status

An ongoing AI fellowship project. The repository documents data exploration and preprocessing; no final model-performance result is claimed here.
