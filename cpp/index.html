CUDA Neural Network Engine

Understand neural networks from matrix storage to GPU kernel execution.

  • C++
  • CUDA
  • GoogleTest
Read the case study +

The problem

High-level ML APIs hide the relationship between matrix operations, backpropagation, and compute cost.

What I did

Built matrix operations, dense layers, forward/backpropagation, and a CUDA matrix-multiplication path with correctness tests and CPU/GPU benchmarks.

Outcome & status

The project reports about 704× speedup for 512×512 multiplication on a Colab Tesla T4 versus its own single-threaded CPU implementation, averaged over five trials. This is a project-specific comparison, not a general library benchmark; CUDA is not yet integrated into the training loop.

What I did

Added make_tensor support for cuda::std::mdspan, C++23 tensor[i, j] syntax, documentation, and tests. The PR records passing C++20 tensor tests; C++23 tests required a newer toolchain during review.

Compression that earns its keep

Let writers skip compression when its storage savings are too small to justify the work.

  • C++
  • PyArrow
  • Parquet V2
Read the case study +

The problem

Parquet V2 pages could keep compressed values even when they were only slightly smaller than the original data.

What I did

Added a configurable min_space_savings threshold in C++ and Python, preserved default behavior, and added unit tests for both implementations.

Outcome & status

Draft PR #52580 is open. The setting lets a value such as 0.1 require at least 10% savings before keeping compressed values. The earlier #52579 submission is closed and shown in the submission history below.
